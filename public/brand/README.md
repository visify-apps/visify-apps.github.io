# Brand assets

Drop Figma exports here when ready. Suggested filenames:

| File | Use |
|------|-----|
| `logo-mark.svg` | Angular V symbol alone |
| `logo-wordmark.svg` | VISIFY APPS wordmark |
| `logo-lockup.svg` | Mark + wordmark combined |
| `logo-mark-inverse.svg` | Mark for dark backgrounds |
| `favicon.svg` | Copy or symlink to `/public/favicon.svg` |

Until these files exist, `Logo.astro` renders a temporary SVG mark + text wordmark using brand colors from `src/styles/tokens.css`.
